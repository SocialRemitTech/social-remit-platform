Download OpenAPI specification:

License: Proprietary — Social Remit Ltd. Internal use only.

Public contract consumed by the Social Remit mobile application. This is the ONLY backend entry point for the app (Baseline 2.0 §2.1.8). No provider identifier, status or error text appears in this contract. The client renders meta.journeyState and meta.nextActions; it never infers journey position from completed screens.
